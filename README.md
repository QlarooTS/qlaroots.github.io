## ⚡ Что это такое

**Zaltett2** — это тонкий клиент для серверов команды QlarooTS, на которых запущен **Zapret**. Расширение сохраняет адрес сервера и открывает текущую страницу через него — поэтому обход блокировки происходит **не на твоём компьютере**, а на стороне сервера.

Никаких локальных демонов, конфигов и возни с роутером. Установил расширение, нажал «Сохранить», смотришь видео.

```
┌────────────────┐      ┌──────────────────────────┐      ┌──────────┐
│ Твой браузер   │  ──▶ │  QlarooTS · Zapret       │  ──▶ │  YouTube │
│ Zaltett2       │      │  сервер по умолчанию     │      │          │
└────────────────┘      └──────────────────────────┘      └──────────┘
```

**Сервер по умолчанию:** [`https://8000-isx0bdbob8dt55f541oxm.e2b.app`](https://8000-isx0bdbob8dt55f541oxm.e2b.app)

## ✨ Возможности

- 🖥️ **Серверная магия** — Zapret работает на сервере команды, локально ничего не запускается.
- ⚡ **Один клик** — кнопка «Открыть текущую страницу» отправляет вкладку через сервер.
- 🔐 **Минимум разрешений** — только вкладки, хранилище и скрипты.
- 🧩 **Manifest V3** — совместимость с актуальными браузерами на базе Chromium.
- 🎯 **Ноль настроек** — адрес сервера уже заполнен по умолчанию.
- 🪶 **Лёгкий вес** — весь архив около 102 КБ.

## 🚀 Быстрый старт

1. **Скачай** [`Zaltett2.zip`](https://qlaroots.github.io/downloads/Zaltett2.zip) и распакуй в отдельную папку.
2. Открой `chrome://extensions` (в Edge — `edge://extensions`) и включи **Режим разработчика**.
3. Нажми **Загрузить распакованное** и выбери эту папку.
4. Открой иконку Zaltett2 → адрес сервера уже заполнен → **Сохранить** → **Открыть текущую страницу**.

Готово. Можно смотреть.

## ⚙️ Конфигурация

Всё самое важное вынесено в [`assets/config.js`](assets/config.js):

| Переменная | Что делает |
| :--- | :--- |
| `defaultServerUrl` | Адрес сервера по умолчанию во всех текстах на странице |
| `serverDisplay` | Текст в декоративном макетеpopup на главной |
| `downloadUrl` | Откуда кнопки качают ZIP |
| `fileName` | Имя файла при скачивании |

Если路由你要 раздавать архив через Google Drive, используй **прямую ссылку на файл**, а не на папку:

```js
downloadUrl: "https://drive.usercontent.google.com/download?id=ID_ФАЙЛА&export=download&confirm=t"
```

## ⚠️ честно о сервере

Расширение открывает страницы через сервер команды. Владелец сервера технически видит запросы — поэтому не указывай в настройках неизвестные адреса. Адреса вида `*.e2b.app` могут перестать отвечать, если превью-окружение засыпает; в этом случае просто поменяй адрес в `config.js` и в ZIP.
